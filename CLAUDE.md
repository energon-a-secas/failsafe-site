# CLAUDE.md — Failsafe

Failsafe — personal emergency protocol builder with encrypted export (failsafe.neorgon.com)

**Live:** failsafe.neorgon.com · **Port:** 8830

## Run

```bash
make serve
```

Then open http://localhost:8830. It must be served over HTTP — the app is ES modules, and `file://` blocks them.

## Architecture

| Module | Lines | Owns |

| `js/events.js` | 473 | `bindEvents` |

| `js/state.js` | 33 | `state`, `loadSaved`, `save`, `getProtocol`, `getStep` |
| `js/app.js` | 14 | — |

Vendored from `packages/neorgon-ui/` — never edit in place, run the sync script instead: `js/neorgon-footer.js`, `js/neorgon-header.js`.

## Data

- `localStorage['PBKDF2']`
- `localStorage['failsafe-v1']`

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
